# 筋トレ種目写真の背景・更新ルール

- 写真は１種目につき１枚、縦長 440 × 550 px の JPG とする。
- 既存の外国人男性モデル、顔、姿勢、ダンベル、必要なベンチを変更しない。手・靴・ダンベルが欠ける切り抜きは採用しない。
- 背景は以前の写真に近い淡いグレーの壁と濃いグレーの床で統一し、種目ごとに室内の照明や背景色を変えない。
- 差し替え対象は 2026-10-26 に登録した `ex_dumbbell_*.jpg` 10 枚。既存の `ex_dumbbell_curl.jpg` や他の写真を誤変更しない。
- 背景修正後は、10枚を目視で点検し、Android の `res/drawable` の同名写真を更新する。
- `training-native/app/build.gradle` の versionCode/versionName を増加させ、旧 APK と同じ署名証明書で署名する。
- APK と `training/latest.json` の SHA-256・バージョン情報を一致させ、スマホのアプリ内「更新」ボタンから取得できるか確認する。
- 実機動作を未確認の場合は必ずそう明記する。
